# Terra Sentinel — Monitoramento, IoT e Automação

[Voltar ao portfólio](../README.md) · [Site do projeto](https://terrasentinel.com.br/)

## Visão geral

Projeto de plataforma modular para monitoramento ambiental e aplicações industriais. Integra aquisição de dados em sensores, transmissão por redes de longa distância, tratamento no servidor, armazenamento, visualização e funções de automação e IA.

## Componentes trabalhados

1. **Dispositivos e firmware:** programação e manutenção de firmware para ESP32/Heltec em C++, aquisição de leituras de sensores e tratamento de comunicação.
2. **Conectividade:** nós e gateways LoRa, telemetria e acompanhamento do estado de comunicação.
3. **Backend:** serviços e APIs com Python/FastAPI, integração com banco de dados e disponibilização de informação para interfaces.
4. **Visualização:** painéis e páginas web para nós, gateways, mapas e medições ambientais.
5. **Geotecnologias:** utilização de mapas e dados geográficos, incluindo GeoJSON/shapefiles.
6. **Indústria:** módulos de acompanhamento de processos com sensores industriais, interface SCADA e integração Modbus RS-485.
7. **IA aplicada:** exploração de análise de medições e geração de alertas, sujeita à validação das regras do sistema.

## Competências demonstradas

**C++ · ESP32 · LoRa · sensores · Python · FastAPI · Linux · Nginx · IoT · APIs REST · integração industrial**
