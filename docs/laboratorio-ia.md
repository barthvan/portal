# Laboratório de IA, Servidores e Automações

[Voltar ao portfólio](../README.md)

## Objetivo

Ambiente de experimentação e desenvolvimento para integrar modelos de linguagem, agentes, APIs, interfaces web e serviços executados localmente ou em servidores Linux.

## Experiência prática

- **Modelos e serviços de IA:** uso e configuração de Ollama, LM Studio, DeepSeek via API e OpenClaw para experimentos e automações.
- **Conceitos e técnicas:** aplicações com LLMs, recuperação de informações (RAG), avaliação de modelos e experimentação com fine-tuning.
- **Orquestração:** integrações entre agentes, endpoints, serviços e fluxos automatizados.
- **Ambientes de execução:** Windows, Linux, Docker, VPS, servidores locais, HTTP/APIs e publicação de aplicações.
- **Diagnóstico:** leitura de logs, correções de configuração, resolução de problemas de conectividade e execução.
- **Ferramentas complementares:** Codex, ComfyUI e outras ferramentas de desenvolvimento assistido e geração de mídia.

## Como pretendo demonstrar

1. Um exemplo independente de API Python com documentação.
2. Um pequeno fluxo de automação com entradas e saídas reproduzíveis.
3. Diagramas de componentes, sem endereços privados, chaves ou tokens.
4. Instruções de reprodução em ambiente de teste sem dependência de serviços proprietários.

Este repositório apresenta experiência prática e **não substitui certificações profissionais**.
